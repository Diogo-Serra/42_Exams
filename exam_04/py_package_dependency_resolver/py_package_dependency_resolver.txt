# Merge Sorted Lists

## Moulinette Rules & Constraints

**Forbidden built-ins / modules:** `sorted()`, `.sort()`, `heapq.merge()`. Use only permitted built-in functions to avoid getting 0 on exam day.

## Assignment

Write a function that merges multiple sorted integer lists into a single sorted list while preserving ascending order.

The function should:
- Take a list of sorted integer lists as input.
- Return a single list containing all elements in ascending order.
- Preserve all duplicate elements, including duplicates across different lists.
- Handle empty lists and negative numbers correctly.
- Return an empty list if the input is empty or contains only empty lists.
- Return a copy of the original list when only one non-empty list is provided.
- Avoid modifying the original input lists.
- Maintain optimal efficiency for large inputs.

## Algorithm requirements

- Use a two-pointer technique to merge two sorted lists.
- Merge neighbouring pairs of lists in rounds.
- Carry any unpaired list into the next round.
- Continue until only one merged list remains.
- Use `<=` when comparing elements to preserve duplicates and maintain stable ordering.
- Do not use any forbidden sorting functions or modules.

## Edge cases to handle

- Empty input: return an empty list.
- Only empty lists: return an empty list.
- Single non-empty list: return a copy of that list.
- Duplicate elements: preserve every occurrence.
- Negative numbers: maintain correct ascending order.
- Lists of different lengths: merge all elements correctly.
- Multiple lists containing the same values: preserve all duplicates.
- Original input: do not modify any input list.

## Notes

- **Two-pointer merging:** Maintain one pointer for each input list and compare their current elements, appending the smaller element to the result.
- **Pairwise merging:** Merge neighbouring lists in rounds instead of merging each new list into one growing result. This avoids repeatedly processing the entire accumulated output.
- **Unpaired lists:** If a round contains an odd number of lists, carry the final list into the next round unchanged.
- **Input preservation:** Copy the non-empty input lists before merging so that the original input is never modified.
- **Duplicates:** Never skip equal values; append each occurrence independently.
- **Complexity:** If \(N\) is the total number of elements and \(k\) is the number of non-empty lists, the time complexity is **\(O(N \log k)\)** and the auxiliary space complexity is **\(O(N)\)**, excluding the input.

The key exam technique is to **combine two-pointer merging with divide-and-conquer**, achieving efficient merging without using any built-in sorting functions.
